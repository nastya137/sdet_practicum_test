Готовое тестовое задание для SDET-практикума Simbirsoft: https://cloud.mail.ru/public/UwPu/CjzGwTKqs
Язык программирования: Java 17
Инструменты:  Selenium Webdriver, JUnit(Java), Maven.
Программа автоматически выполняет заданную последовательность действий и сохраняет скриншот страницы сразу после выполнения теста в папке проекта.

Требования для запуска:
- JDK 17;
- Maven.

Запуск теста на Windows:
1. Установить JDK 17 и Maven, если они не были установлены ранее.
2. Проверить наличие системной переменной JAVA_HOME, которая должна содержать путь к JDK.
3. В системной переменной Path добавить путь к директории maven/bin.
4. В консоли перейти в директорию проекта и выполнить:
   mvn compile
5. Также выполнить в консоли
   mvn test
